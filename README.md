## Задача 1.3. Подготовка данных и создание dataset

### Основной dataset по вакансиям

Для построения основных визуализаций был создан dataset на основе таблицы `default.HH`.

В dataset добавлены расчетные поля:

- `salary_avg_rub` - расчетная зарплата для анализа с конвертацией в рубли;
- `employment_clean` - тип занятости с обработкой пустых значений;
- `schedule_clean` - график работы с обработкой пустых значений.

[Запрос SQL на создание датасета](/sql/hh_vacancies_dataset_Berkut_D.sql)

**Логика расчета salary_avg_rub**

Сначала рассчитывается базовое значение зарплаты: если указаны `salary_from` и `salary_to`, берется среднее между ними. Если указано только одно из значений, используется оно. Если зарплата не указана, значение `salary_avg_rub` остается `NULL`.

После этого значение приводится к рублям по полю `salary_currency`: 
- для `RUR` и пустого значения зарплата остается без изменений
- для `EUR` умножается на `87`
- для `USD` умножается на `77`.

---

### Dataset по ключевым навыкам

Так как поле `key_skills` содержит несколько навыков в одной строке через запятую, для анализа навыков был создан отдельный dataset. В нем каждый навык вынесен в отдельную строку.

[Запрос SQL на создание датасета](/sql/hh_key_skills_dataset_Berkut_D.sql)

**Логика подготовки ключевых навыков**

В исходной таблице все ключевые навыки одной вакансии находятся в поле `key_skills` в виде строки:

```text
Java, Spring Framework, PostgreSQL, Docker
```

Для анализа навыков строка разбивается по запятой. После этого каждый навык становится отдельной строкой:

| id | key_skill |
|---:|---|
| 107650257 | Java |
| 107650257 | Spring Framework |
| 107650257 | PostgreSQL |
| 107650257 | Docker |

Такой dataset можно использовать для построения графика топ навыков.

---

### Созданные datasets

В Superset были созданы два virtual dataset на основе SQL-запросов из SQL Lab:

- `hh_vacancies_dataset_Berkut_D` - основной dataset для анализа вакансий, зарплат, городов, технологий, опыта и динамики публикаций.
- `hh_key_skills_dataset_Berkut_D` - отдельный dataset для анализа ключевых навыков из поля `key_skills`.

Данные физически не копировались в отдельные таблицы. Dataset в Superset хранит SQL-запрос и использует его как источник для построения визуализаций.
